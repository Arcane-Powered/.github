# Arcane Powered

A game launcher for Windows, macOS and Linux. It gathers the games you own on other launchers into one library and backs up their saves.

[arcane-powered.com](https://www.arcane-powered.com) · [Roadmap](https://www.arcane-powered.com/roadmap) · [Discord](https://discord.gg/GpR4QS6Srk) · [LinkedIn](https://www.linkedin.com/company/arcane-powered)

## Available in the beta

- One library for Steam, Epic Games, GOG, itch.io, Ubisoft Connect, EA app, Battle.net, Xbox app, Minecraft, CurseForge and Hytale, plus games installed outside a launcher and 50 emulators.
- Automatic cloud saves, once you've confirmed the save folder.
- A history of each save, so you can go back to an earlier version.
- When two PCs disagree, you choose which version to keep. Nothing is overwritten.
- Collections, a storage manager and save sharing.

## Planned

- Emulator save states.
- An open database of the save folders players have confirmed.
- A mod manager, plus guides, forums and news for each game.
- A store with editions, DLC and regional pricing.
- A marketplace where you can resell games, in euros. The platform estimates the price, which never goes above the new price. The publisher decides whether resale is allowed and takes a share of 0 to 40%. The platform takes 10%. Once a game is sold, the licence moves to the buyer.
- An SDK for studios: sessions, achievements, presence and lobbies.

The [roadmap](https://www.arcane-powered.com/roadmap) shows where each one stands.

## Privacy

- The client sends path templates, never the layout of your PC.
- Saves are never shared between accounts.
- You can export all your data.
